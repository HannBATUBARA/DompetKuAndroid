DompetKuAndroid

Aplikasi keuangan pribadi offline untuk Android.

Fitur

- Pencatatan pemasukan dan pengeluaran
- Target tabungan
- Anggaran per kategori
- Catatan utang dan piutang
- Laporan dan grafik bulanan
- Penyimpanan data lokal di perangkat

Desain

Tema hijau elegan dengan tampilan sederhana dan mudah digunakan.
